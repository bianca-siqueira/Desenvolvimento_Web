# Desenvolvimento_Web

Como rodar o programa?

1. Abrir um terminal cmd
2. Colocar o caminho das pastas onde está localizada o arquivo "page.js"
3. Rodar o comando de instalação "npm install"
4. Rodar o comando para a página web "npm run dev"
5. Abrir no seu navegador o site local no endereço que aparecer, ex: "http://localhost:3000/"
